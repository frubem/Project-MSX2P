# OMEGA an MSX 2+ Computer Clone

This repository documents the complete development of a functional
MSX 2+ Clone, following the schematics, 
layout, and design principles.

The project is organized into multiple hardware-specific
sub-repositories. Each one contains schematics, PCB layouts,
documentation, and photos related to a specific module of the system.

The goal is to faithfully reproduce a MSX 2+ Clone
architecture while documenting the full hardware development process.

1) Omega an MSX 2+ Clone: https://github.com/frubem/omega 
2) Omega DC-DC adaptor: https://github.com/frubem/Omega_DC-DC_adaptor_1.5
3) O4MEGA an 4MB Ram expansion for Omega MSX 2+: https://github.com/frubem/O4MEGA
4) F4 register and FMPAC combo board for Omega MSX 2+: https://github.com/frubem/F4-FMPACv2
5) Case: https://github.com/frubem/Carcasa_Omega
6) Floppy Disk Interface for Omega MSX 2+ - ver 1: https://github.com/frubem/MSX-TDC-600
7) Floppy Disk Interface for Omega MSX 2+ - ver 2: https://github.com/frubem/fdd-cdx2
8) MSX-BEER a simple IDE Interface: https://github.com/msx-solis/MSX-BEER
9) MSX IDE Sunrise clone: https://github.com/msx-solis/MSX_IDE_Clon_SUNRISE
10) MultiController is a FDD-IDE combo controller: https://github.com/frubem/MultiController
11) MSXSDMapperV2: https://github.com/frubem/msxsdmapperv2
12) SDMMR 1024K: https://github.com/polileco/sdmmr
13) Wozblaster is an OPL4 sound expansion cartridge: https://github.com/frubem/wozblaster
14) Obsonet is a network interface: https://github.com/frubem/obsonet
15) MSX-USB: https://github.com/frubem/MSX-USB
16) TRH9000 The Yamaha V9990 based open-source video card for the MSX: https://github.com/frubem/trh9000
17) Carnivore2 MultiFunctional Cartridge: https://github.com/frubem/Carnivore2
